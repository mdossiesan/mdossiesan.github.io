# DSJ · Dos Santos Jesus

Source for the website at https://mdossiesan.github.io, served by GitHub Pages.

- `index.html`: home page
- `tracking/`: the tracker (meals with AI photo scanning, exercise, calendar, goals)
- `notes/`: personal notes
- `assets/`: shared styles and scripts; `assets/config.js` holds the Supabase project settings
- `supabase/`: database setup (`schema.sql`) and the `scan-food` server function

See [SETUP.md](SETUP.md) to turn on sign-in, sync and AI food scanning.
